## ♡ what I'm learning

Tecnologia muda o tempo todo, e eu gosto de explorar o que existe além do que já conheço.

- 🐾 **Arquitetura de software:** microsserviços, APIs e comunicação entre serviços.
- 💌 **Mensageria:** conceitos e uso do RabbitMQ.
- 🐳 **Containers:** Docker e fundamentos de Kubernetes.
- 🧪 **Qualidade de software:** testes automatizados, regressão e E2E.
- 🔍 **Leitura de código:** entender implementações, investigar bugs e revisar mudanças.
- ✨ **IA no desenvolvimento:** usando ferramentas como Claude Code para explorar soluções, com foco em compreender o código gerado.

Meu objetivo não é só fazer o código funcionar, mas entender **por que funciona, como foi construído e como posso melhorá-lo**.
